# assets/audio

Здесь лежит фоновый музыкальный трек `background.mp3`. Он играет по кругу от кнопки «Начать» до конца письма; громкость меняется ползунком «музыка» (старт 70 %).

Запасной вариант: если файл не загрузится, музыка синтезируется прямо в браузере (Web Audio API, см. `src/js/audio.js`).

## Как заменить трек

1. Положить новый файл сюда под тем же именем `background.mp3` (mp3 — самый совместимый формат для мобильных браузеров).
2. Больше ничего менять не нужно: путь уже прописан в `src/js/audio.js` (константа `TRACK_SRC`).
3. Если сайт уже опубликован, поднять `CACHE_VERSION` в `service-worker.js`, чтобы устройства не держали старый трек.

Желательно: спокойное зацикливание без резкого стыка в конце, вес до ~3 МБ (открывать будут с телефона).

Если нужен вариант только с синтезом (без файла) — поставить `TRACK_SRC = null` в `src/js/audio.js`.
