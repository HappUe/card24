# assets/audio

Сюда кладётся фоновый музыкальный трек, когда он будет выбран.

Пока трека нет, музыка синтезируется прямо в браузере (Web Audio API, см. `src/js/audio.js`) — внешние файлы не нужны, лендинг полностью рабочий.

## Как подменить на настоящий трек

1. Положить файл сюда под именем `background.mp3` (mp3 — самый совместимый формат для мобильных браузеров).
2. В `src/js/audio.js` найти строку с константой `TRACK_SRC` и убрать у неё значение `null`, поставив путь:
   `const TRACK_SRC = 'assets/audio/background.mp3';`
3. Всё. Синтезированная заглушка выключится сама, останется как запасной вариант, если файл не загрузится.

Желательно: длительность от 1 минуты, спокойное зацикливание без резкого стыка в конце, вес до ~3 МБ (лендинг будут открывать с телефона).
